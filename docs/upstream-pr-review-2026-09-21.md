## Specification checks

- [OOXML table indentation](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.tableindentation?view=openxml-3.0.1): percentage/auto indentation and non-left justification must not be interpreted as an ordinary twip indent.
- [OOXML level restart](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.levelrestart?view=openxml-3.0.1): restart rules include an explicit never-restart value, which #217 does not model.
